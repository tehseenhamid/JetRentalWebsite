# Image assets and prompts

Four destination-inspired images were created using the built-in imagegen tool. These are illustrative AI-generated scenes, not verified photographs of specific airports, hotels, residences or available aircraft. Existing jet/cabin imagery is retained.

New WebP assets have 480, 800 and 1280 pixel widths. Browser srcset selection, lazy loading and explicit aspect ratios reduce mobile transfer and layout shifts. Original generated PNG masters remain in the local image-generation archive; website deployment uses only the optimized WebP files.

## New York

Files: assets/new-york-480.webp, assets/new-york-800.webp, assets/new-york-1280.webp

Prompt: Use case: product-mockup / editorial website artwork. Create one premium cinematic landscape illustration of Manhattan skyline across the Hudson River, architectural silhouettes, a quiet sunrise, dimensional buildings and atmospheric depth. Sophisticated photorealistic 3D-render quality with tactile materials, believable architecture, rich depth, elegant navy shadows, warm champagne highlights, restrained natural colors. Wide landscape composition 3:2, clean editorial travel photography mood for a high-end private aviation website, visually rich full bleed, focal subject around center, usable as a tall card crop too. No text, no letters, no airport codes, no logos, no watermarks, no frame, no infographic, no collage. Destination-inspired artwork, not a map or promise of exact landmarks.
